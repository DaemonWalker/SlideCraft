# 快速开始

## 1. 准备环境

需要 Node.js 18 或更高版本，以及随 Node.js 安装的 npm。项目源码和 `package.json` 均位于 `app/`，以下命令都应在该目录执行。

## 2. 安装并启动

从项目根目录执行：

```bash
cd app
npm install
npm run dev
```

开发服务器默认使用 7100 端口；如果已被占用，会自动尝试下一个可用端口。启动后打开终端输出的本地地址。

可用脚本：

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 执行 TypeScript 类型检查并构建 |
| `npm run build:offline` | 当前等同于 `npm run build`，生成单文件离线版 |
| `npm run preview` | 预览构建结果 |

`dev` 和 `preview` 脚本均已监听 `0.0.0.0`；需要覆盖端口时，在 `--` 后传入 Vite 参数。

## 3. 使用演示功能

| 功能 | 操作 |
| --- | --- |
| 下一页 | `→`、`PageDown`、`Space` 或底部右侧按钮 |
| 上一页 | `←`、`PageUp` 或底部左侧按钮 |
| 首页 / 末页 | `Home` / `End` |
| 页面总览 | `O` 或工具栏“总览”，点击条目跳转 |
| 当前页讲师备注 | `N` 或工具栏“备注” |
| 进入 / 退出全屏 | `F` 或工具栏“全屏” |
| 快捷键帮助 | `?` 或工具栏帮助按钮 |
| 关闭弹层 / 退出全屏 | `Esc` |
| 触屏翻页 | 单指水平滑动 |
| 定位页面 | 地址末尾使用 `#/1`、`#/2` 等 |
| 放大图片 | 点击使用 `ImageFigure` 的图片；`Esc`、遮罩或关闭按钮退出 |
| 切换语言 | 工具栏右上角语言菜单 |

语言选择保存在当前浏览器的 `localStorage` 中。`http://` 和 `file://` 的存储区域可能独立，清除浏览器数据后会恢复中文。

## 4. 尝试第一次修改

1. 在 `app/src/decks/demo/slides/` 中选择一个示例页面。
2. 修改页面结构时编辑对应 `.vue` 文件。
3. 修改可见文案时，同时编辑 `app/src/i18n/index.ts` 中 `zh-CN`、`ja`、`en` 三份字典。
4. 在浏览器中检查页面，并切换三种语言确认没有缺漏或溢出。
5. 执行 `npm run build` 验证类型和构建。

当前 `App.vue` 的页面标题、章节、时长和备注也按页面 `id` 从多语言字典读取，因此不要只修改 `decks/demo/index.ts` 中的对应字段。
